Secure Microsoft 365 Copilot — Oversharing & SharePoint Permissions Remediation

A repeatable method to discover, remediate, and verify the SharePoint Online / OneDrive access that governs what Microsoft 365 Copilot can surface. Copilot reasons over Microsoft Graph content — files, sites, pages, chats — and returns anything the prompting user technically has permission to open. If a site is shared with "Everyone Except External Users," if an anonymous link is live, or if a user carries stale membership from a former role, Copilot can pull that content into a response. This solution closes that gap by fixing the underlying permissions, not by turning Copilot off. - Copilot
