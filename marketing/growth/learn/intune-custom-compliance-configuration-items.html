Intune Custom Compliance & Configuration Items (Scripted)

Intune custom compliance lets you evaluate device state that the built-in compliance settings can't reach — a registry value, a running service, an installed app version, a security control specific to your organization. It works by pairing two artifacts: 1. A PowerShell detection script that runs on the device and returns a small JSON payload of the values it discovered. 2. A JSON rule file that tells Intune how to judge those values (operators, thresholds) and what remediation message to show the user when a value fails.
