# Sales Content — Commercial-to-GCC High Microsoft 365 & Azure Migration Program

## Hook
**One coordinated program to move your whole estate to the sovereign cloud.**

GCC High is a separate sovereign cloud — a new tenant and a cross-cloud migration of Exchange,
SharePoint/OneDrive, Teams, Azure IaaS servers, apps, and AVD/VDI, driven by Quest On Demand,
ShareGate, and Azure Migrate/ASR.

## Run it yourself — simpler, cheaper, and proven
- **Simpler** — one program model sequencing seven workstreams (Discover → Plan → Provision → Pilot →
  Migrate → Cutover → Validate → Decommission); every object named and reused.
- **Cheaper** — one fixed price vs. a six-figure integrator engagement; reusable across the estate.
- **Tested** — pilot-by-workstream with per-workstream pass/fail + acceptance gates.

## What's inside
- Overview, Requirements (verify + implement-if-missing) + category Global Requirements, the program
  runbook (provision GCC High + per-workstream runbooks), Testing, Troubleshooting, Best Practices.
