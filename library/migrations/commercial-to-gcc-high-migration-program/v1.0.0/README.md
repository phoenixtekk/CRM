A program playbook — **Discover → Assess → Plan → Provision → Pilot → Migrate → Cutover → Validate →
Decommission** — coordinating per-workstream runbooks to move an entire estate to GCC High, with
ITAR/CMMC discipline and per-workstream acceptance gates.
