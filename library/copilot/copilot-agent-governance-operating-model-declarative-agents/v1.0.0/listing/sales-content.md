## The hook

Your users can now build their own AI agents in minutes. This is the operating model that keeps them
owned, approved, and safe. Copilot Studio agents already pass an admin approval gate; an **Agent
Builder** declarative agent shared with *"Anyone in your organization"* can reach the whole tenant
**with no approval at all**. That specific gap is what this product closes.

## The problem it solves

Ungoverned agent build-up: **ownerless** agents (the maker left), **unreviewed** agents (shared wider
than anyone assessed, over data nobody reviewed), and **shadow** agents (running with no registry
entry and no accountable owner). No packaging tool, DLP policy, or label taxonomy answers *who owns
this agent, who said it could go into business use, who is it shared with, and when does it get
retired.*

## What's inside

- Four-role accountability model (Agent Owner, Business Sponsor, Data & Security Reviewer, Agent
  Admin) + RACI + escalation rules.
- Intake & approval gate and a standing Agent Review Board — closing the org-wide-sharing gap.
- Standards, sharing policy, and periodic access review.
- Full lifecycle & retirement (block-then-delete discipline).
- The exact admin-center enforcement — Copilot Control System agent access & sharing controls, Agent
  Registry block / reassign / publish — verified against Microsoft Learn (2026-07-24).
- Plugs into existing Purview DLP, oversharing remediation, and Entra/Defender "Agents at risk"
  signals without re-teaching them.
- Five read-only, cloud-aware (Global / USGov / USGovDoD) Microsoft Graph PowerShell scripts.
