# Sales Content — Microsoft Edge for Business: Enterprise Configuration & Security Baseline (Intune)

## Hook
**Stop shipping Edge at its out-of-the-box defaults.** Turn Microsoft Edge into a managed, hardened,
standardized browser across your Windows fleet with Intune — password manager off, Edge enforced as the
default, SmartScreen and PUA on, extensions controlled, IE mode for legacy apps, and the Microsoft Edge
security baseline as the hardening floor.

## The problem
The browser is the most-used app on every endpoint, and it usually runs wide open. Security assessments
keep flagging the same two items: the **built-in password manager is enabled** (competing with the
corporate vault) and **Edge isn't enforced as the primary browser** (so managed protections apply
inconsistently). Behind those two findings sits a bigger gap — unmanaged SmartScreen/PUA, freely
installed extensions, no work-profile sign-in governance, no defined update channel, and legacy IE-only
line-of-business apps with nowhere to run once IE is retired.
