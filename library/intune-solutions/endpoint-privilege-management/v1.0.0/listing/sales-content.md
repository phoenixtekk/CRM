## Product: Endpoint Privilege Management (EPM) — Commercial
- **SKU:** PTK-EPM-COMM-001
- **Price:** $1,495.00
- **Category:** Intune Solutions

**Short description**
A complete, deploy-it-today package for rolling out Endpoint Privilege Management on Intune-managed
Windows devices. Remove standing local admin rights, let users run as standard, and allow only the
applications you approve to elevate — controlled, audited, and implementable by a single
administrator in a controlled pilot within a day.

**Full description (highlights)**
- End standing local admin while keeping legitimate elevations working, via **certificate/hash-based elevation rules** (automatic, user-confirmed, support-approved).
- Includes: Executive Summary, Solution Overview, Requirements Guide, click-by-click Implementation Guide, 5 PowerShell scripts, Testing Guide, Troubleshooting Guide, Best Practices.
- Built on the Phoenixtekk model: **Assess → Configure → Pilot → Validate → Expand** — observe real elevations first, then enforce.
- Value: smaller attack surface, least-privilege/Zero Trust posture, and a tenant-wide audit trail of every privileged action.
- Delivered as branded Word + PDF and a scripts ZIP.

> **Licensing note:** EPM requires the **Microsoft Intune Suite** or the standalone **Endpoint
> Privilege Management add-on** (not included in base Intune Plan 1). The package shows you how to
> verify and assign it.
