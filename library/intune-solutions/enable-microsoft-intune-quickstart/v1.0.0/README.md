A free preview product that enables Microsoft Intune from scratch — new tenant or existing — with the
basics/defaults to reach a **functioning Intune** that can enroll a **Windows PC** and an **iPhone (BYOD)**.

## What's included
- 8 source docs (exec summary, overview, requirements, implementation, enrollment scenarios, testing,
  troubleshooting, best practices, deliverables summary) + the Intune category global-requirements.
- 5 read-only PowerShell scripts: `ITSTART-Discovery`, `ITSTART-Validate`, `ITSTART-Report`,
  `ITSTART-Enrollment-Readiness`, `ITSTART-Compliance-Check`.
- Complete Solution Package ZIP (PDF + Word + scripts).

## Apple Business Manager boundary
Corporate zero-touch iOS (ADE) requires Apple Business Manager, which lives outside Intune. This guide
points to the paid catalog solution **`entra-id-abm-account-auto-provisioning-intune`** for the full ABM
walkthrough rather than reproducing it.
